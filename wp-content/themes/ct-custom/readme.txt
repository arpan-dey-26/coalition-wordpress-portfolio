Responsive Coalition assessment theme based on Underscores.

== Description ==

Editable Contact homepage, native Theme Settings, WordPress menus, and Contact Form 7 integration.

== Installation ==

1. In your admin panel, go to Appearance > Themes and click the Add New button.
2. Click Upload Theme and Choose File, then select the theme's .zip file.
3. Click Activate to use your new theme.
