# CT Custom

Classic Underscores theme for the Coalition assessment. The Homepage template uses the supplied Contact composition. No external fonts, icon packages, or build step are required.

## Page configuration

1. Activate CT Custom.
2. Create a page titled **Homepage** and select the **Homepage** template.
3. Insert the **Contact homepage** pattern.
4. In Settings → Reading, choose a static front page and select Homepage.
5. In Appearance → Theme Settings, select the logo and enter contact information and social links.
6. Create and assign the Primary menu and Utility menu.

## Contact Form 7

When CF7 is installed, create a form and replace the pattern's `[ct_contact_form]` shortcode with the shortcode copied from CF7, or supply its ID as `[ct_contact_form id="YOUR_FORM_ID"]`.

Without a configured form, the pattern displays a disabled preview with an unavailable message.

## Design notes

The desktop reference is 1600 × 756 with a centered approximately 960-pixel content area. Responsive adjustments are implemented for smaller screens.
